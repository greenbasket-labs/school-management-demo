# Demo build status

This repository is the destination for the real School Management System demo deployment.

The intended final state is:

1. Full real application copied from `greenbasket-labs/school-management-system`.
2. Demo-only visitor entry with no password prompt.
3. Prepared identities for Owner, Musa Ibrahim, Johno Okafor, Student and Parent.
4. 180+ SS1–SS3 students and 12+ teachers, with linked parents and realistic school history.
5. Dedicated demo database.
6. Visitor writes isolated from the permanent baseline through a reset/disposable-session mechanism.

Until the full application tree is present, deployment should not be treated as ready for production traffic.
